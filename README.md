# SQL Basics

This repository documents my understanding of SQL and how backend systems use databases.

## What I understand so far
- Backend uses SQL to read and modify data in databases
- Databases store data in tables
- Tables have rows (records) and columns (fields)
- SQL supports CRUD operations (Create, Read, Update, Delete)
